# Heizungsanlagenmanager via BSB-LAN

Die Heizungsregelung über BSB-LAN bedienen: Kategorien wie am Kessel,
Zeitschaltprogramme als Wochentabelle, Sollwerte stellen – und die Werte nach
Home Assistant bringen, wahlweise durch das Add-on oder durch BSB-LAN selbst.

Die vollständige Beschreibung steht in [DOCS.de.md](DOCS.de.md)
([English](DOCS.md)) und im Reiter *Dokumentation* des Add-ons.
